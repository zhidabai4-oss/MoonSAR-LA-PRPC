# Locally Adaptive Piecewise RPC Modeling for Lunar South Polar SAR Orthorectification

Data and software accompanying the manuscript **Locally Adaptive Piecewise RPC Modeling for Lunar South Polar SAR Orthorectification**.

**Authors:** Zhida Bai, Yuming Xiang, Doudou Hu, Shijie Liu, Jinyang Chen, Huan Xie, and Xiaohua Tong.

## Public downloads

- [LA-PRPC algorithm program and example data](https://github.com/zhidabai4-oss/MoonSAR-LA-PRPC/releases/tag/software-20261022)
- [Regional Mini-RF S1 orthomosaic](https://github.com/zhidabai4-oss/MoonSAR-LA-PRPC/releases/tag/mosaic-20261026)

The software package provides the Windows x64 implementation of LA-PRPC, example data, and the supporting files needed to run the examples. The data release provides the lunar south polar Mini-RF S1 orthomosaic and its accompanying metadata.

See [download and extraction instructions](DOWNLOAD_AND_EXTRACT.md) and [SHA-256 checksums](SHA256SUMS.txt).
